# Aplicacion de votaciones PH

Este directorio contiene el frontend React/Vite y el backend Express/Socket.IO.

Configuracion de Render: Root Directory `asamblea-app`; Build Command `npm install --include=dev && npm run build`; Start Command `npm start`.

Las credenciales deben permanecer en variables de entorno de Render. No subir archivos `.env` ni enlaces JWT de propietarios.
